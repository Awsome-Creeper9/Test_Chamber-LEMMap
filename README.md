# Test Chamber

This is a Portal-inspired map. There are many portal-like gimmicks in this map.
- Aerial Faith Plate - Visually is a stone pressure plate in front of magenta glazed terracotta; the arrow points to the direction you'll be launched and the target is the landing position.
- Tractor Beam - Visually represented with light blue glass display entities; it causes you to float and pushes you from the lime concrete to the red concrete.
- Propulsion (Orange) Gel - Represented by orange carpet; grants speed to the player.
- Repulsion (Blue) Gel - Represented by light blue carpet; grants jump boost to the player and is bouncy.
- Portal - Blue portal teleports you to orange portal.
- Fall Damage is disabled in this map.

This is a repository for a custom LEM modtools map.

[LEM-ModTools documentation](https://docs.legacyminigames.net/en/latest/modtools/landing.html)
